Inspecting a model without mistaking a signal for a cause

A zoo's classifier labels a dog correctly. Its keepers still hesitate to trust it: perhaps it recognizes a fence that usually appears behind dogs. At a frontier laboratory, a new language-model checkpoint passes routine training checks, yet reasoning scores fall, jailbreak successes rise, and tool-using agents become slower. Both teams ask the same consequential question: which measurement would distinguish a useful hypothesis from an attractive story?

The zoo case lets us derive exactly what input gradients, path attributions, occlusion, activation maps, synthetic inputs, and backward projections measure. The laboratory case asks how to combine those habits with training telemetry, evaluation and data diagnostics. The transition is from explaining one chosen scalar of a fixed function to investigating changes in a whole system. A bright heatmap and a smooth loss curve each answer a narrower question than whether a deployed model is reliable.

1. Three regressions, several possible explanations 0:05

Provenance. Lecture: the constructed 200-billion-parameter checkpoint, audience hypotheses and four diagnostic categories, approximately 5–898 s. Original construction: the measurement and intervention distinction used throughout this chapter.

A checkpoint is a saved set of model parameters together with enough configuration to run the model. The opening scenario supplies three observed changes, not a documented training incident. Reasoning is a capability measured on selected tasks; jailbreak success is measured under selected adversarial attempts; agent latency includes the application surrounding the model. They need not share a cause. A damaged training batch might hurt reasoning, an altered safety policy might affect refusal, and a slow tool service might increase latency without changing the network at all.

Freeze the failing checkpoint and its predecessor before changing anything. For each comparison keep task inputs, decoding policy, tool versions and measurement units explicit. If yesterday's benchmark used a different reasoning budget, a score change cannot be assigned solely to the new parameters. If today's application added an external lookup, end-to-end time has changed even when token generation has not. Reproducible comparison means identifying what was held fixed, rather than merely saving two dashboard screenshots.

The recording organizes candidate evidence into training and scaling, representations and internals, data and distribution, and capabilities and safety. These categories differ in what is observed. Loss and gradient norms describe optimization. Attention and activations describe a computation on an input. Data ledgers describe exposure and sampling. Evaluations describe outcomes on a stated task population. Agreement among the categories can narrow a hypothesis; no category makes every other one unnecessary.

An intervention deliberately changes a suspected component while holding relevant alternatives fixed. Replaying the same tool response to both checkpoints tests whether external service variation explains latency. Replacing one training-data tranche in otherwise matched small runs tests a data hypothesis. Removing a neuron and measuring an output change tests a particular computational dependence. Such tests concern the model or experiment being manipulated. They do not automatically establish why an animal behaves as it does, why a person chose a word, or why a real-world distribution changed.

Our operating rule is therefore precise: name the object measured, the allowed change, and the conclusion supported. The zoo provides an unusually tangible place to practice that rule before returning to frontier-model dashboards.

2. A fixed zoo classifier and a scalar to explain 14:57

Provenance. Lecture: animal classification, human supervision, feature maps and image-level testing, approximately 898–1193 s. Original construction: the persistent formal model and two-feature diagnostic fixture.

Let an image be a vector \(x\in[0,1]^{n_x}\), where \(n_x\) counts all pixel-channel values after a fixed normalization. Let \(\theta\) denote trained parameters, held fixed during explanation. A convolutional neural network computes hidden activations \(h^{[\ell]}(x)\) at layer index \(\ell\), then real class scores \(u_k(x)\) for animal classes \(k=1,\ldots,K\). Its reported probability is

\[\hat y_k(x)=\frac{\exp(u_k(x))}{\sum_{j=1}^{K}\exp(u_j(x))}.\]

A score \(u_k\), also called a logit, is dimensionless and need not be positive. The probabilities sum to one. A convolutional feature volume has height \(n_H\), width \(n_W\), and \(n_{\mathrm{ch}}\) channels; an entry \(h^{[\ell]}_{ij\nu}\) is the activation at spatial row \(i\), column \(j\), channel \(\nu\). A feature map fixes \(\nu\) and retains the spatial array. A rectified linear unit, or ReLU, applies \(\max(0,u)\) to a preactivation \(u\).

We want to explain the dog score \(u_{\mathrm{dog}}\) on one photograph, while retaining the same \(x,\theta,h,u,\hat y\) across methods. Changing from a logit to a probability changes the question. Changing the image baseline changes the reference. Changing the network head changes the function itself. These are meaningful experimental choices, not interchangeable plot settings.

For arithmetic, a two-coordinate original fixture stands in for image features. Its coordinates \(x_1,x_2\) lie in \([0,1]\); they could represent normalized fur and background evidence, but those semantic names are stipulated for the example. Initially take \(u_{\mathrm{dog}}(x)=x_1\) and \(u_{\mathrm{cat}}(x)=2x_2\). Later fixtures explicitly replace this simplified score by a small ReLU network or a linear pooling head. Each isolates one mechanism; none is claimed to reproduce a trained zoo network.

The keepers also need ordinary evaluation: mistakes across species, lighting, camera position and unfamiliar backgrounds, with human review of failures. Classification confidence measures the output distribution of this fixed model; it is not a probability that the explanation is correct. A plausible map on one image is useful for proposing a test, while reliability requires performance evidence over the images and decisions the zoo will actually encounter.

3. Saliency: local sensitivity and class competition 19:52

Provenance. Lecture: input gradients and pre- versus post-softmax scores, approximately 1193–1390 s. Research extension: Simonyan, Vedaldi and Zisserman, PDF pp. 2, 4. Original construction: the Jacobian derivation and competing-class counterexample.

The signed saliency vector is \(S_k(x)=\nabla_xu_k(x)\in\mathbb R^{n_x}\). Its coordinate \(i\) reports the rate of change of the chosen score per unit change in pixel-channel value \(x_i\), with other coordinates fixed. For a small perturbation \(\delta\in\mathbb R^{n_x}\), differentiability gives the first-order expansion

\[u_k(x+\delta)=u_k(x)+S_k(x)^\top\delta+o(\|\delta\|_2).\]

The remainder divided by \(\|\delta\|_2\) tends to zero as the perturbation vanishes. This is what makes the gradient locally informative. It gives no bound for a large occluding square unless additional smoothness holds throughout that change. At a ReLU kink, a single ordinary derivative may not exist; implementations choose a backward convention, which must not be confused with a theorem of differentiability.

For a color display, Simonyan et al. take the maximum absolute derivative over the color channels at each spatial position (p. 4). Other displays sum absolute values or retain a signed channel. An absolute-value display discards whether a pixel increase helps or hurts dog classification. A map normalized separately for each image also discards comparable magnitudes between images. State the channel reduction, sign handling and color scale before interpreting a bright region.

Why the softmax changes the question

Differentiate the softmax quotient with respect to one logit \(u_j\). The numerator contributes \(\mathbb{1}[k=j]\exp(u_k)\), where \(\mathbb{1}[E]\) is one if event \(E\) holds and zero otherwise; the denominator contributes \(\exp(u_j)\). Dividing the resulting quotient by the common denominator twice gives

\[\frac{\partial\hat y_k}{\partial u_j}=\hat y_k\bigl(\mathbb{1}[k=j]-\hat y_j\bigr),\qquad \nabla_x\hat y_k=\hat y_k\left(\nabla_xu_k-\sum_{j=1}^{K}\hat y_j\nabla_xu_j\right).\]

The second identity is the chain rule summed over all class logits. Its subtraction is the hinge: a dog probability can increase because competing logits decrease. A probability gradient measures relative competition, while a logit gradient measures change in the selected raw score. Both are mathematically legitimate; a claim that they explain the same object is not.

In the zoo fixture, at \(x=(1,1)\), the dog logit is 1 and the cat logit is 2. The dog probability is \(1/(1+e)=0.268941\). Set the background coordinate \(x_2\) to zero. The dog logit remains exactly 1, the cat logit falls to zero, and dog probability becomes \(e/(1+e)=0.731059\). At the original point the derivatives with respect to \(x_2\) are \(\partial u_{\mathrm{dog}}/\partial x_2=0\) and \(\partial\hat y_{\mathrm{dog}}/\partial x_2=-2\hat y_{\mathrm{dog}}\hat y_{\mathrm{cat}}=-0.393224\). The apparent background importance in the probability map is entirely due to the cat competitor (engineering check).

A logit itself is also representation dependent. Adding the same input-dependent function to every logit leaves all probabilities unchanged while changing each logit's gradient. Consequently “explain the logit” requires specifying the actual model's score convention. If the operational question concerns a dog-versus-cat decision, the margin \(u_{\mathrm{dog}}-u_{\mathrm{cat}}\) is invariant to that common shift and can be a useful alternative scalar.

The recording presents saliency as a segmentation sanity check. Localization and segmentation differ: a segmentation assigns a class to each pixel; a gradient assigns local score sensitivity. A flat gradient can reflect saturation, and a background gradient can reflect legitimate context or a shortcut. Neither observation alone determines the zoo's acceptance decision.

4. Integrated gradients: a reference, a path and an accounting identity 23:09

Provenance. Lecture: the black-to-image path and retinal illustration, approximately 1390–1505 s. Research extension: Sundararajan, Taly and Yan, pp. 2–4, 6–7. Original construction: proofs with explicit regularity, saturation and ReLU fixtures, and a quadrature bound.

A local derivative can vanish even when an input differs consequentially from a reference. Integrated gradients addresses that question by accumulating gradients between a baseline \(x_{\mathrm{base}}\in\mathbb R^{n_x}\) and the observed input \(x\). The baseline is a chosen reference, such as a black image in the model's input coordinates. Black before normalization need not equal a zero vector after normalization; the preprocessing map is part of the definition.

Let \(\delta_{\mathrm{path}}=x-x_{\mathrm{base}}\) and let \(\zeta\in[0,1]\) index the straight path \(x_{\mathrm{base}}+\zeta\delta_{\mathrm{path}}\). For coordinate \(i\), the attribution to the dog logit is

\[\mathrm{IG}_i(x)=\delta_{\mathrm{path},i}\int_0^1\frac{\partial u_{\mathrm{dog}}(x_{\mathrm{base}}+\zeta\delta_{\mathrm{path}})}{\partial x_i}\,d\zeta.\]

The derivative has score-per-input units, and multiplying by \(\delta_{\mathrm{path},i}\) makes the attribution have score units. A negative contribution is allowed. The formula explains a difference from a specific reference, rather than assigning a baseline-free meaning to every pixel.

Proposition 1: completeness along an admissible path. If the score composed with the path is absolutely continuous, its derivative agrees almost everywhere with the gradient dotted with \(\delta_{\mathrm{path}}\), and the partial derivatives along the path are integrable, then \(\sum_i\mathrm{IG}_i(x)=u_{\mathrm{dog}}(x)-u_{\mathrm{dog}}(x_{\mathrm{base}})\).

Proof. The chain rule along the path gives \(d u_{\mathrm{dog}}(x_{\mathrm{base}}+\zeta\delta_{\mathrm{path}})/d\zeta=\sum_i \delta_{\mathrm{path},i}\partial u_{\mathrm{dog}}/\partial x_i\) almost everywhere. There are finitely many coordinates, so exchange the sum and integral. The fundamental theorem of calculus for an absolutely continuous function gives

\[\sum_i\mathrm{IG}_i(x)=\int_0^1\frac{d}{d\zeta}u_{\mathrm{dog}}(x_{\mathrm{base}}+\zeta\delta_{\mathrm{path}})\,d\zeta=u_{\mathrm{dog}}(x)-u_{\mathrm{dog}}(x_{\mathrm{base}}).\]

This proves the identity. For a continuous piecewise affine ReLU network, ordinary-gradient integration applies when the chosen path meets its nondifferentiable set only at finitely many crossings: the gradient exists between crossings and those isolated points carry no integral mass. A path can instead lie on a kink for a whole interval. For example, \(\operatorname{ReLU}(x_1-x_2)\) is not ordinarily differentiable on the path \(x_1=x_2\), even though its value along that path is constant. Such a path requires a stated backward convention and verification that its chosen signals obey the path chain rule. Ambient almost-everywhere differentiability alone does not establish that fact. Absolute continuity of the composed score is what licenses the final integral equality.

What completeness rescues, and what it leaves open

Consider the scalar function \(u(x)=\min(1,\max(0,x))\). At \(x=2\), its derivative is zero. From baseline zero, the straight path \(2\zeta\) crosses its increasing region for \(0\lt\zeta\lt1/2\). Hence integrated gradients is \(2\int_0^{1/2}1\,d\zeta=1\), equal to \(u(2)-u(0)\). From baseline 1.5, the path lies entirely on the saturated plateau and the attribution is zero. Neither answer is a contradiction: the two references ask different questions.

For a two-coordinate fixture, extend the numerical domain temporarily to \([0,2]^2\) and take \(u(x)=\operatorname{ReLU}(2x_1-x_2-1)+\tfrac12\operatorname{ReLU}(x_2)\). At \(x=(2,1)\) from baseline \((0,0)\), the first preactivation along the path is \(3\zeta-1\), active for \(\zeta\gt1/3\). Thus the first coordinate receives \(2\cdot2\cdot(2/3)=8/3\); the second receives \(-1\cdot(2/3)+1/2=-1/6\). Their sum is \(5/2=u(2,1)-u(0,0)\). The endpoint gradient is \((2,-1/2)\); multiplying it by the input gives total \(7/2\), which misses the bias-related region crossing (engineering check).

Completeness is an accounting constraint, not a guarantee of clinically useful or causal explanation. The recording's retinal example compares highlighted regions with lesions. The primary paper's Figure 3 illustrates that correspondence on a particular retinal image (p. 6); it establishes neither population diagnostic accuracy nor that those highlighted pixels caused disease. For the zoo, test baseline sensitivity as deliberately as score sensitivity: a black background, a blurred image and a reference animal can induce different paths through unfamiliar inputs.

The finite computation

With a positive integer \(n_{\mathrm{int}}\) integration steps, a right-endpoint approximation replaces the integral by the mean of gradients at \(\zeta_j=j/n_{\mathrm{int}}\), \(j=1,\ldots,n_{\mathrm{int}}\). Suppose the scalar integrand for coordinate \(i\) is Lipschitz on the path with constant \(B_i\ge0\): changing \(\zeta\) by an amount changes the integrand by at most \(B_i\) times that amount. On one interval of width \(1/n_{\mathrm{int}}\), the integral of the distance to its right endpoint is \(1/(2n_{\mathrm{int}}^2)\). Summing the errors over intervals yields

\[|\widehat{\mathrm{IG}}_i-\mathrm{IG}_i|\le\frac{|\delta_{\mathrm{path},i}|B_i}{2n_{\mathrm{int}}}.\]

This bound explains convergence under its smoothness hypothesis. A ReLU gradient that jumps at a region boundary is not globally Lipschitz, so applying the same bound to it would be invalid. One can integrate its affine regions exactly, or refine a grid and monitor the completeness residual. A small residual verifies total accounting; cancellation can conceal large coordinate errors. It is useful evidence about numerical integration, not a complete quality metric for a map.

5. Occlusion: ask a finite counterfactual of the fixed model 25:05

Provenance. Lecture: square masking and the Pomeranian, wheel and Afghan-hound examples, approximately 1505–1714 s. Research extension: Zeiler and Fergus, p. 5 and Figure 7 on p. 7. Original construction: cost arithmetic and the comparison with a derivative.

Choose a square side \(n_{\mathrm{occ}}\) in pixels and a fill value in the same normalized coordinates as \(x\). For each allowed spatial location \((i,j)\), let \(x^{\mathrm{occ}}_{ij}\) be the image with that square replaced by the fill. Define the logit drop \(u_{\mathrm{dog}}(x)-u_{\mathrm{dog}}(x^{\mathrm{occ}}_{ij})\). A positive drop means this particular replacement lowers the dog logit; a negative drop means it raises it. If instead the map reports the remaining true-class probability, as in the source demonstration, its sign and object of explanation differ from the logit-drop map.

For image height \(n_H\) and width \(n_W\), square positions fully inside the image, and a scan stride \(n_{\mathrm{str}}\), the number of locations is

\[n_{\mathrm{loc}}=\left(\left\lfloor\frac{n_H-n_{\mathrm{occ}}}{n_{\mathrm{str}}}\right\rfloor+1\right) \left(\left\lfloor\frac{n_W-n_{\mathrm{occ}}}{n_{\mathrm{str}}}\right\rfloor+1\right).\]

The formula assumes positive stride and a square that fits both dimensions. A 224-by-224 image with a 16-pixel square and an 8-pixel stride has \(27^2=729\) locations. With the original image, that is 730 forward evaluations, which can be batched but still require computation. It is a count of evaluations, not 730 times the latency of one production call: batching and hardware utilization change elapsed time.

Why can occlusion disagree with saliency? For a differentiable score, the exact difference along a segment is the integral of its gradient dotted with the finite perturbation. The endpoint gradient replaces that varying integrand by one local value. Masking can cross ReLU boundaries and create an input unlike any training image. The finite answer and the local answer measure different changes, so agreement is a useful diagnostic rather than an identity.

Zeiler and Fergus systematically occlude images with a gray square and monitor the classifier (p. 5). Their Figure 7 illustrates falling true-class probability when the square covers a Pomeranian's face, a car wheel, or an Afghan hound (empirical result for those examples). In the hound scene, the recording points out higher dog probability when a human face is covered, approximately 1652–1714 s. Our competing-logit fixture already shows why this need not mean the human was negative dog evidence: the dog score could stay fixed while a rival score falls.

For the zoo, repeat an important finding with more than one fill and square size. If a dark square produces a large drop but an inpainted replacement does not, the original conclusion may depend on an artificial edge. Controlled background swaps test a distinct, more semantic hypothesis. None of these manipulations establishes the causal role of a scene feature outside the fixed classifier without further assumptions about how real images are generated.

6. Class activation maps: an exact decomposition for a particular head 28:34

Provenance. Lecture: replacing flattening and three fully connected layers by global average pooling and one linear layer, approximately 1714–2214 s. Research extension: Zhou et al., pp. 1–3, and Selvaraju et al., pp. 4–5. Original construction: the bias-aware mean identity and a nonlinear counterexample.

The zoo wants a map on every camera frame. Global average pooling, abbreviated GAP, computes one spatial mean per channel of the final convolutional volume \(h^{[\ell_{\mathrm{conv}}]}\). Here \(\ell_{\mathrm{conv}}\) is the last convolutional layer index. Define \(\bar h_\nu=(n_Hn_W)^{-1}\sum_{i,j}h^{[\ell_{\mathrm{conv}}]}_{ij\nu}\), with \((i,j)\) running over the feature map's height and width. A linear class head with learned weights \(W_{k\nu}\) and bias \(b_k\) gives \(u_k=\sum_\nu W_{k\nu}\bar h_\nu+b_k\).

Distribute the finite sums to define \(\mathrm{CAM}_k(i,j)=\sum_\nu W_{k\nu}h^{[\ell_{\mathrm{conv}}]}_{ij\nu}\). Then

\[u_k=\frac1{n_Hn_W}\sum_{i,j}\mathrm{CAM}_k(i,j)+b_k.\]

This is an exact score decomposition for the stated head. It is not an equality between a softmax probability and a spatial sum. The bias contributes independently of any location. A positive channel weight and a high activation contribute positive evidence to the raw score; negative weights can contribute negative evidence even if all feature activations are nonnegative. Discarding negative map values changes the accounting.

Take two 2-by-2 maps with entries \((1,2,3,4)\) and \((4,3,2,1)\), in row-major order. For dog weights \((2,-1)\) and bias 0.5, the channel means are both 2.5, so the dog score is \(2(2.5)-2.5+0.5=3\). The four CAM entries are \((-2,1,4,7)\); their mean is 2.5 and adding the bias recovers 3 (engineering check). The negative upper-left region is part of this identity, even though a positive-only display would suppress it.

The orange channel on slide 13 has 16 integer entries whose sum is 1675. Its GAP value is \(1675/16=104.6875\), rounded to 104.7 (engineering check). The mean loses spatial arrangement: two maps with the same entries permuted have the same pooled value. What remains available for localization is the unpooled feature map, combined with the head's weights. Saying that pooling loses no spatial information would misstate the mechanism.

Flattening followed by several nonlinear fully connected layers does not generally admit this linear decomposition. For a scalar two-location feature with values 0 and 2, consider the nonlinear head \(u=\operatorname{ReLU}(\bar h-1)=0\). Averaging pointwise \(\operatorname{ReLU}(h-1)\) gives 0.5. The nonlinearity and the spatial mean cannot be exchanged. Replacing a trained head by GAP and a new linear layer therefore changes the classifier and requires training and renewed evaluation. It is not an explanation retrofit that leaves every prediction fixed. Zhou et al.'s affiliation is MIT (p. 1); the recording's Berkeley attribution is a bibliographic error.

Grad-CAM for the unchanged network

Grad-CAM starts from a chosen convolutional activation volume in the existing network and its gradient to the selected class logit. Let \(\Gamma_{k\nu}=(n_Hn_W)^{-1}\sum_{i,j}\partial u_k/\partial h_{ij\nu}\) be the mean gradient for channel \(\nu\). Selvaraju et al. form \(\operatorname{ReLU}(\sum_\nu\Gamma_{k\nu}h_{ij\nu})\) (pp. 4–5). The gradient weights provide a local approximation to a possibly nonlinear downstream computation. The outer ReLU deliberately retains positive support.

For our GAP-linear head, each derivative is \(W_{k\nu}/(n_Hn_W)\), so the mean gradient equals that same value. Before the ReLU, Grad-CAM is CAM divided by \(n_Hn_W\). This constant is often removed by display normalization; it must remain if exact score accounting is claimed. Outside that architecture, there is no corresponding exact sum identity. Upsampling either map to image resolution interpolates a coarse map; it does not recover fine pixel evidence that the feature grid never retained.

The recording names Grad-CAM and discusses a live CAM video. The fixed slide still and source papers motivate the algorithms here. They do not establish a verified frame rate for the zoo's hardware or correct localization on every moving animal. Test those deployment properties directly after choosing the explanation object and architecture.

7. Synthetic inputs: what a score rewards under a regularizer 36:53

Provenance. Lecture: class and unit visualization, fixed-weight pixel ascent and goose/flamingo interpretations, approximately 2214–2579 s. Research extension: Simonyan et al., p. 2; Yosinski et al., pp. 2, 5–6. Original construction: the analytic optimum and feasibility distinction.

A map explains a particular input. Activation maximization asks what input produces a large chosen score. With the model parameters fixed, maximize the objective \(J(x)=u_{\mathrm{dog}}(x)-\lambda\Omega(x)\), where \(\lambda\ge0\) controls a chosen penalty \(\Omega\). For the squared Euclidean penalty \(\Omega(x)=\|x\|_2^2\), an ascent step of size \(\eta\gt0\) is

\[x\leftarrow x+\eta\bigl(\nabla_xu_{\mathrm{dog}}(x)-2\lambda x\bigr).\]

If image values must lie in \([0,1]\), project the result coordinatewise onto that box after the step. A penalty on magnitude does not enforce the box: it merely discourages large values. Conversely, clipping values into range does not make an image natural. These two constraints solve different problems. On mean-centered inputs, the natural pixel bounds must first be transformed by the same preprocessing.

For a linear logit \(u(x)=w^\top x+b\) and \(\lambda\gt0\), complete the square:

\[J(x)=b+\frac{\|w\|_2^2}{4\lambda}-\lambda\left\|x-\frac{w}{2\lambda}\right\|_2^2.\]

The unconstrained optimum is \(x_{\mathrm{opt}}=w/(2\lambda)\); the box-constrained optimum clips these coordinates to the allowed interval because the squared-distance problem separates by coordinate. For \(w=(2,-1)\), \(\lambda=1\), the unconstrained answer is \((1,-0.5)\), while the \([0,1]^2\) answer is \((1,0)\). For \(\lambda=0\), a nonzero linear score has no finite maximum on all of \(\mathbb R^{n_x}\), although it has a maximum on the box. The penalty's practical purpose is therefore mathematically visible without claiming it produces fur, eyes or anatomy.

A nonlinear network gives a nonconcave objective; the initial image and optimization schedule can lead to different local maxima. Yosinski et al. describe unnatural high-frequency patterns and large pixel values from unregularized optimization, then investigate penalties and operators that improve visual interpretability (pp. 2, 5–6). Those reported improvements are empirical results describing properties of their network and visualization procedure, not a theorem about natural images.

The recording interprets repeated geese and flamingos in synthesized images as evidence of how labels may have been learned, approximately 2429–2521 s (speaker judgment). Such a hypothesis should be checked against actual examples and labels: repeated motifs can arise from the optimization procedure and receptive-field geometry as well as dataset frequency. To investigate a unit instead of a class, replace \(u_{\mathrm{dog}}\) in the objective by one defined activation \(h^{[\ell]}_{ij\nu}\). The optimization variable remains the input, and the resulting image still answers “what maximizes this objective under these constraints?”

8. Real examples and the region a unit can access 42:58

Provenance. Lecture: dataset search, cropped top activations and increasing receptive fields, approximately 2579–2936 s. Research extension: Zeiler and Fergus, pp. 3–4; Luo et al., pp. 1–3. Original construction: receptive-field recurrence and selection counterexample.

For a fixed channel \(\nu\) and layer \(\ell\), run each validation image through the network and rank its maximum spatial activation \(\max_{i,j}h^{[\ell]}_{ij\nu}(x)\). Retain the maximizing location as well as the image identifier. Ranking each coordinate separately answers a different question from maximizing over locations; both should be stated. The top examples show what strongly activates a channel within the available dataset, which keeps the stimulus on real images rather than on the optimization's synthetic manifold.

Top examples still suffer selection. Suppose every dog in a validation collection stands beside the same type of fence, while no other species does. A fence detector's strongest five examples are all dogs. Labeling it a “dog neuron” from those examples confounds animal and background. Add fence-only images and dogs without fences, then compare activation and output changes. One channel can also respond to multiple patterns; a clean top gallery does not prove its response is exclusive.

To crop the area relevant to a selected activation, compute its theoretical receptive field, the input coordinates connected to it through the layer geometry. In one dimension, let \(n_{\mathrm{rf}}^{[\ell]}\) be the receptive-field width in original input entries and \(n_{\mathrm{jump}}^{[\ell]}\) the spacing between neighboring layer-\(\ell\) centers in those entries. Start with both equal to 1 at layer zero. For a nondilated layer with filter width \(n_f^{[\ell]}\) and stride \(n_{\mathrm{str}}^{[\ell]}\),

\[n_{\mathrm{jump}}^{[\ell]}=n_{\mathrm{str}}^{[\ell]}n_{\mathrm{jump}}^{[\ell-1]},\qquad n_{\mathrm{rf}}^{[\ell]}=n_{\mathrm{rf}}^{[\ell-1]}+(n_f^{[\ell]}-1)n_{\mathrm{jump}}^{[\ell-1]}.\]

The derivation uses the union of \(n_f^{[\ell]}\) consecutive lower-layer receptive intervals. Moving from the first to last adds \(n_f^{[\ell]}-1\) jumps; subsampling changes future spacing by the stride. Thus a 3-wide stride-1 convolution, a 2-wide stride-2 pool, then a 3-wide stride-1 convolution yields widths \(3,4,8\) and jumps \(1,2,2\). Padding changes where the interval sits and how much overlaps real pixels; dilation changes the effective filter span. Width alone cannot locate a crop's center or account for boundaries.

The theoretical field describes possible dependence. Luo et al. define an effective field through gradient impact, which depends on weights and often the input (p. 2). In their simplified linear stacks, multiple computational paths concentrate impact near the center; their analysis and experiments find effective regions smaller than the full theoretical field (pp. 1–3; theoretical and empirical results within their settings). A large support does not mean equal influence over that support.

For the zoo, store full images beside cropped patches. The crop explains geometric access; the full scene exposes confounders that cropping could hide. The slide's approximate 80-by-80 third-layer field is an illustrative source number, not a universal CNN constant. The recurrence and actual architecture determine the field of your own network.

9. What convolution discards 48:56

Provenance. Lecture and slides 23–26: the one-dimensional stride-2 example. Original construction: an explicit distinction between padded coordinates and genuine input coordinates. Dumoulin and Visin, pp. 19–24: transpose geometry.

To project an activation toward input space, first understand the forward map. For eight genuine entries \(x=(x_1,\ldots,x_8)^\top\), add two zeros on either side and use the four-tap filter \((-1,0,0,1)\), stride 2, without a bias or nonlinear activation. We use the cross-correlation convention usual in neural-network implementations: the filter is not reversed during the forward operation. The slide's printed filter contains an extra zero; its matrix and calculation specify this four-tap operation. The output is

\[u=W_{\mathrm{in}}x=(x_2,\ x_4-x_1,\ x_6-x_3,\ x_8-x_5,\ -x_7)^\top.\]

The input length formula gives \(\lfloor(8+2\cdot2-4)/2\rfloor+1=5\). Let \(P:\mathbb R^8\to\mathbb R^{12}\) insert the padding, and let \(W\in\mathbb R^{5\times12}\) put \(-1,+1\) at columns \((1,4),(3,6),(5,8),(7,10),(9,12)\), respectively. Then \(W_{\mathrm{in}}=WP\). Writing \(u=W(Px)\) makes convolution an ordinary linear map on a structured input; it does not make padded zeros into free unknowns.

There cannot be a unique inverse from five outputs to eight unconstrained inputs. Indeed, adding the same amount to \(x_1,x_4\) leaves \(x_4-x_1\) unchanged. The same is true of the pairs \(x_3,x_6\) and \(x_5,x_8\). These three independent directions constitute the null space of \(W_{\mathrm{in}}\); each row has an independent pivot, so its rank is 5. The unrestricted padded-domain matrix \(W\) instead has a seven-dimensional null space. Counting dimensions in the wrong domain gives the wrong account of what was lost.

For \(x=(1,2,3,4,5,6,7,8)^\top\), the output is \((2,3,3,3,-7)^\top\). Many different inputs give that output. Even restricting pixels to an interval does not generally identify a unique input: when a pair lies strictly inside the interval, a sufficiently small common displacement remains feasible. Architectural constraints narrow possible preimages; they do not restore information discarded by the operation.

Upsampling appears in segmentation, image generators and decoder networks because those systems need outputs with more coordinates than a compressed representation. Their decoder learns a useful prediction from retained features. That task is different from proving that every original input can be recovered.

10. A transpose is a backward linear map, not an inverse 54:58

Provenance. Lecture and slides 26–28: transposed convolution and zero insertion. Original derivation: adjoints, pseudoinverses and the padding-dependent counterexample. Dumoulin and Visin, pp. 19–24.

The transpose is characterized by \(\langle W_{\mathrm{in}}x,\upsilon\rangle=\langle x,W_{\mathrm{in}}^\top \upsilon\rangle\) for every \(x\in\mathbb R^8,\upsilon\in\mathbb R^5\), using Euclidean inner products. Consequently, if a differentiable scalar objective depends on \(u=W_{\mathrm{in}}x\), its input gradient is \(W_{\mathrm{in}}^\top\nabla_u J\). This is the chain rule and a statement about sensitivity. It is not a statement that \(W_{\mathrm{in}}^\top u=x\).

\[W_{\mathrm{in}}^\top \upsilon=(-\upsilon_2,\ \upsilon_1,\ -\upsilon_3,\ \upsilon_2,\ -\upsilon_4,\ \upsilon_3,\ -\upsilon_5,\ \upsilon_4)^\top.\]

The source's padded-domain rows are mutually orthogonal and have squared norm 2, so \(WW^\top=2I_5\). Its minimum-norm right inverse is \(W^+=\frac12W^\top\), and \(W^+W\) is an orthogonal projection in \(\mathbb R^{12}\). It recovers only the component orthogonal to the null space. It can assign nonzero values to coordinates that were padding in the forward experiment.

For the actual eight-dimensional input, \(W_{\mathrm{in}}W_{\mathrm{in}}^\top=\operatorname{diag}(1,2,2,2,1)\), because the first and last rows touch one genuine entry each. Therefore

\[W_{\mathrm{in}}^+=W_{\mathrm{in}}^\top\operatorname{diag}(1,\tfrac12,\tfrac12,\tfrac12,1),\qquad W_{\mathrm{in}}W_{\mathrm{in}}^+=I_5.\]

Applying this to our output gives \((-1.5,2,-1.5,1.5,-1.5,1.5,7,1.5)^\top\), not \((1,\ldots,8)^\top\). It has the same output and is the preimage of smallest Euclidean norm. In particular, simply halving \(W_{\mathrm{in}}^\top u\) is wrong at the boundary: it halves the uniquely determined entries \(x_2,x_7\). A pseudoinverse is a reconstruction rule with an explicit norm criterion; it is an inverse only on an appropriate restricted subspace.

Zero insertion implements the transpose efficiently. Interleave four zeros into \(\upsilon\) to obtain \((\upsilon_1,0,\upsilon_2,0,\upsilon_3,0,\upsilon_4,0,\upsilon_5)\). Full mathematical convolution with \((-1,0,0,1)\) produces the 12 entries \(W^\top \upsilon\); crop two entries from each end to obtain \(W_{\mathrm{in}}^\top \upsilon=P^\top W^\top \upsilon\). A library that expresses this as cross-correlation instead reverses the kernel and sets the corresponding padding. State the convention, rather than trying to remember one diagram's arrows.

For dilation 1, a transposed-convolution output length is \((n_{\mathrm{in}}-1)n_{\mathrm{str}}-2n_{\mathrm{pad}}+n_f+n_{\mathrm{outpad}}\). Here it is \((5-1)2-4+4=8\). The output-padding parameter resolves an ambiguity in the desired shape when multiple input lengths share a forward output length. It adds no recovered information. A learned decoder can choose its own weights; using the transpose of a particular forward operator is one mathematically defined backward map.

11. Pooling switches and three different ReLU rules 59:27

Provenance. Lecture and slides 29–33; Zeiler and Fergus, pp. 2–3; Springenberg et al., PDF p. 9. Original construction: negative pooling and sign counterexamples.

Max pooling records the largest entry in a window. Retaining its maximizing position, called a switch, allows a backward projection to place one value at that position and zeros elsewhere. For disjoint windows and a fixed unique maximum, ordinary backpropagation routes the incoming derivative through that switch. Ties need a stated convention. Overlapping windows may send multiple contributions to the same coordinate, which must be added.

Switch unpooling does not reconstruct the discarded nonmaximal values. It is a right inverse of max pooling under additional conditions: in a nonnegative pooled window, the inserted maximum beats or ties all inserted zeros. If the original window is \((-4,-3,-2,-1)\), its pooled value is \(-1\); zero-filled unpooling gives \((0,0,0,-1)\), whose maximum is 0. Thus even re-pooling equality fails for negative pooled values. A preceding ReLU supplies the nonnegativity condition in the common visualization setting.

13. Attention, embeddings and circuits 1:13:15

Provenance. Lecture and slides 42–44; Vaswani et al., p. 4; Vig, pp. 1–2; Jain and Wallace and Wiegreffe and Pinter; the 2021 circuits framework and Olsson et al. (2022). Original construction: equal-value attention counterexample.

A transformer's representations are token vectors rather than spatial image maps, but the measurement discipline survives. Let \(\mathsf Q,\mathsf K\in\mathbb R^{n_{\mathrm{seq}}\times n_{\mathrm{key}}}\) be query and key matrices and \(\mathsf V\in\mathbb R^{n_{\mathrm{seq}}\times n_{\mathrm{val}}}\) the value matrix of one self-attention head. Its attention weights and output are

\[\mathsf A=\operatorname{softmax}_{\mathrm{row}}\!\left(\frac{\mathsf Q\mathsf K^\top}{\sqrt{n_{\mathrm{key}}}}+\mathsf M\right),\qquad h^{\mathrm{attn}}=\mathsf A\mathsf V.\]

The mask \(\mathsf M\) has 0 at allowed positions and effectively \(-\infty\) at forbidden positions; a causal decoder forbids future tokens. Assume every queried row has at least one allowed key with a finite score. Then each row of \(\mathsf A\) sums to one over allowed keys; an entirely masked row has an undefined softmax and requires separate implementation handling. Vaswani et al.'s variance motivation assumes independent zero-mean, unit-variance query and key components: the dot product then has variance \(n_{\mathrm{key}}\), and dividing by its square root makes that variance 1. Real learned components need not satisfy those assumptions exactly.

Attention specifies how values are combined inside this head, not a derivative of the final class score with respect to each input token. If two scalar values both equal 2, attention rows \((0.9,0.1)\) and \((0.1,0.9)\) both produce 2. Distinct attention patterns can therefore have identical head output. Conversely, a small weight can matter when its value is large or when downstream computation amplifies it. Other heads, residual paths, feedforward blocks and later layers also contribute.

Jain and Wallace's “Attention is not Explanation” investigates attention-based NLP models and presents weak alignment with other importance measures and alternative attention distributions. Wiegreffe and Pinter's response argues that the interpretation claim and its tests must be specified, and supplies alternative tests in recurrent models. These are not a blanket proof that transformer attention never helps. They distinguish a useful inspection display from an unsupported universal explanation claim.

Vig's BertViz exposes attention at several views, including head and neuron-level relationships. A display can help locate candidate dependencies. Confirm a candidate with a declared intervention, such as changing a token or ablating an attention contribution, and measure the resulting scalar. These interventions are different: changing a token also changes its representation and other computational paths.

Embedding plots likewise need a declared objective. t-SNE constructs high-dimensional neighborhood probabilities \(p_{ij}^{\mathrm{hi}}\) and low-dimensional heavy-tailed probabilities \(p_{ij}^{\mathrm{map}}\), then minimizes \(\sum_{i\ne j}p_{ij}^{\mathrm{hi}}\log(p_{ij}^{\mathrm{hi}}/p_{ij}^{\mathrm{map}})\). The superscripts name the two spaces. Nearby original points get substantial target probability. If their plotted probability is much smaller, the logarithmic ratio contributes a strong penalty, which explains the emphasis on preserving neighbors. A two-dimensional layout cannot generally reproduce all distances in a much higher-dimensional manifold; the heavy tail gives moderately separated points more room than a Gaussian map would. Distances between separated islands, apparent island areas and coordinates on the display are not automatically calibrated measures of semantic distance, frequency or causal separation. Check neighborhoods in the original representation, stability across plotting settings and examples within each apparent cluster.

The Transformer Circuits framework published in December 2021 separates query–key routing from output–value transformations and analyzes small attention-only models. Olsson et al.'s March 2022 induction-head work studies a pattern that can complete “A B … A” with “B.” It reports empirical results with stronger causal evidence in small attention-only models and more correlational evidence in larger models with feedforward blocks. The slide's 2023 labels do not change those publication dates. Nor should a teaching focus on small models be converted into a claim that no larger-model circuit analysis is possible. Match each conclusion to the model and intervention actually studied.

14. Training telemetry and compute allocation 1:18:06

Provenance. Lecture and slides 45–46; Kaplan et al., p. 6; Hoffmann et al., pp. 1, 5–6. Original construction: constrained allocation and diagnostic ledger.

Return to the failing checkpoint. Plot training and held-out loss with learning rate, gradient norms, optimizer state anomalies and throughput on a common time axis. Define each denominator: loss in nats per token, throughput in processed tokens per second, utilization relative to a named hardware peak. A spike coinciding with a learning-rate change and a spike coinciding with data replacement imply different next experiments. Synchrony narrows candidates; it does not establish cause.

For a dense transformer, a useful approximation is \(C_{\mathrm{train}}\approx6N_{\mathrm{param}}N_{\mathrm{tok}}\) FLOPs, counting nonembedding parameters and processed training tokens. A weight's forward multiply-add costs roughly 2 FLOPs per token; backward work for activations and weights adds roughly twice that forward work. This is an estimator with omitted attention/context and other terms, not an exact hardware count. Sparse experts require an active-computation account; multiplying total stored parameters by every token can substantially overestimate their work. Repeated tokens still incur computation and are counted as processed tokens here.

Kaplan et al.'s WebText2 fits allocate their estimated minimum training compute \(C_{\mathrm{min}}\) approximately as \(N_{\mathrm{param}}\propto C_{\mathrm{min}}^{0.73}\), while processed training-token exposure scales as \(C_{\mathrm{min}}^{0.27}\). The latter exponent adds their fitted batch-size and step exponents \(0.24+0.03\), since exposure is batch tokens times steps (PDF p. 5; empirical result: fitted allocation). Their minimum-compute convention, model family and training procedure must accompany these exponents. They are not universal rates or the constants of Hoffmann et al.'s parametric fit below.

A scaling fit predicts loss over a stated family and range. It does not diagnose a sudden corrupted batch or prove an individual checkpoint is healthy. Hoffmann et al. revisit compute allocation and find approximately equal scaling of model size and training tokens under their compute-optimal fits: their training-curve-envelope approach gives empirical fitted exponents about 0.50 and 0.50, while their IsoFLOP approach reports about 0.49 and 0.51 (empirical result: fitted allocation). The allocation recommendation depends on the model family, fitting procedure, loss target and compute convention.

Their empirical test trains Chinchilla with 70 billion parameters using the budget of the 280-billion-parameter Gopher, and reports stronger performance across their evaluated downstream tasks (pp. 1–2). Chinchilla uses 1.4 trillion training tokens; the abstract describes approximately four times Gopher's data. This is the authors' reported same-budget experiment, not a claim that every rounded parameter-and-token product is exactly equal under the simple \(6N_{\mathrm{param}}N_{\mathrm{tok}}\) estimator. This empirical result demonstrates that allocating a fixed training budget to a smaller model and more tokens can improve performance in the studied setting. It does not establish one universal ratio for every dataset, context length or inference-cost objective.

We can derive why the exponents change. Use an illustrative held-out-risk fit

\[\mathcal R_{\mathrm{fit}}=\mathcal R_{\mathrm{floor}}+ \Lambda_{\mathrm{param}}N_{\mathrm{param}}^{-\xi_{\mathrm{param}}} +\Lambda_{\mathrm{tok}}N_{\mathrm{tok}}^{-\xi_{\mathrm{tok}}},\qquad C_{\mathrm{train}}=6N_{\mathrm{param}}N_{\mathrm{tok}},\]

with positive coefficients and exponents. This uses the functional form of Hoffmann et al.'s third, parametric-fit approach (p. 6), translated into the book's notation. The derivation below is an original teaching derivation; no fitted numerical constants are borrowed from chapter 1's different Kaplan fit. Substitute \(N_{\mathrm{tok}}=C_{\mathrm{train}}/(6N_{\mathrm{param}})\). At a positive interior minimum, differentiating with respect to \(N_{\mathrm{param}}\) gives

\[\xi_{\mathrm{param}}\Lambda_{\mathrm{param}}N_{\mathrm{param}}^{-\xi_{\mathrm{param}}} =\xi_{\mathrm{tok}}\Lambda_{\mathrm{tok}}\left(\frac{6N_{\mathrm{param}}}{C_{\mathrm{train}}}\right)^{\xi_{\mathrm{tok}}}.\]

Solving yields \(N_{\mathrm{param}}\propto C_{\mathrm{train}}^{\xi_{\mathrm{tok}}/(\xi_{\mathrm{param}}+\xi_{\mathrm{tok}})}\) and \(N_{\mathrm{tok}}\propto C_{\mathrm{train}}^{\xi_{\mathrm{param}}/(\xi_{\mathrm{param}}+\xi_{\mathrm{tok}})}\). Equal fitted exponents give square-root allocation. This stationary point is the unique positive minimum: in log model size the two variable terms are positive exponentials with opposite slopes, whose sum is strictly convex and diverges at both ends. Memory ceilings, inference costs, discrete model sizes or a different risk model change the feasible optimum.

For the opening incident, compare observed loss with a fit only after checking that tokenizer, held-out mixture and loss aggregation remained fixed. A checkpoint can have ordinary average loss yet fail a narrow reasoning slice. Conversely, a changed held-out mixture can raise aggregate loss with unchanged per-domain performance. The fit is one reference curve; the domain ledger determines whether the comparison has the same meaning.

15. Capability, contamination and safety are separate measurements 1:25:14

Provenance. Lecture and slides 47–49; Brown et al., PDF p. 43; OpenAI–Anthropic's August 2025 pilot report. Original construction: paired comparison and contamination estimands.

A capability evaluation needs more than a model name and a percentage. Save the checkpoint identifier, task version, prompts, tool permissions, decoding and reasoning budgets, scoring procedure, exclusions and repeated-run policy. For each task, compare both checkpoints on the same cases. This reduces variation from case difficulty and makes individual disagreements inspectable.

For \(n_{\mathrm{test}}\ge2\) independent paired binary outcomes, let \(\mathrm{Diff}_i\) be new correctness minus old correctness, so \(\mathrm{Diff}_i\in\{-1,0,1\}\). The estimated improvement is \(\widehat{\mathrm{Gain}}=\sum_i\mathrm{Diff}_i/n_{\mathrm{test}}\). An estimated standard error is \(\sqrt{\widehat{\mathrm{Var}}_{\mathrm{Diff}}/n_{\mathrm{test}}}\), where \(\widehat{\mathrm{Var}}_{\mathrm{Diff}}=\sum_i(\mathrm{Diff}_i-\widehat{\mathrm{Gain}})^2/(n_{\mathrm{test}}-1)\). Independence is an assumption about test cases, not a reward for having many correlated paraphrases. Stochastic decoding introduces another source of variation; use matched sampling policies and account for repeated runs rather than treating every generated answer as an independent new task.

A benchmark can be contaminated by training exposure. Define the overlap statistic before computing it. A fraction of distinct test \(n\)-grams found in training differs from the fraction of test examples containing any matching \(n\)-gram. Tokenization, normalization, common phrases and the match threshold change both. Brown et al.'s analysis uses word 13-grams after lowercasing and whitespace normalization without punctuation, then removes 200-character windows around matches. That historical protocol is evidence of one procedure, not a universal definition of contamination.

A finite original example makes the denominator consequential. Normalize to lowercase whitespace-delimited words and use word bigrams. Training text “the dog sees the fence” has four distinct bigrams. Test cases “the dog runs” and “cat sleeps” have three distinct bigrams between them; only “the dog” matches training. The distinct-bigram overlap is \(1/3\), while the fraction of test examples with any match is \(1/2\). Neither number is a capability score. A different punctuation or tokenizer policy can change the sets, so retain that policy with the statistic.

High overlap can arise from boilerplate; low exact overlap can coexist with paraphrased exposure. No matching 13-gram therefore does not prove a test is unseen. Nor does removing contaminated examples guarantee an unbiased remaining test: the removed cases may be easier, harder or concentrated in a domain. Report the full and filtered results with removal counts and domain composition, and use fresh private or otherwise controlled evaluations when the intended claim requires stronger evidence of novelty.

Safety evaluations measure outcomes under specified adversarial and ordinary conditions. OpenAI's report on the joint pilot published August 27, 2025 describes a cross-company pilot (product claim) across areas including jailbreaks, misalignment and instruction hierarchy. Some tests relax safeguards to probe model propensities; the report warns that such stress tests do not directly quantify real-world threat likelihood. Preserve that condition when interpreting results. A password-protection test is an instruction-following probe; its score is not a recommendation to store secrets inside a language-model conversation.

The recording also uses contemporary product scoreboards. Mistral's “Mistral 3” announcement is dated December 2, 2025, the lecture date (product claim; dated vendor announcement). Such dated vendor announcements provide historical context, with their declared evaluation settings. They do not establish a current model ranking. The slide's label “GPT-5 technical report” points to product-announcement material; no numerical claim here relies on that page.

For our incident, keep capability loss, adversarial success and agent latency as separate outcome series. If a reasoning task fails only when a tool response is delayed, replaying the same response tests an application hypothesis. If jailbreak success rises with changed refusal prompts while task accuracy stays fixed, the prompt layer deserves examination. If reasoning fails with identical tools and prompts, investigate computation and training exposure. The measurements guide targeted experiments; they do not entitle one dashboard to explain every failure.

16. Data composition and sparse routing 1:32:43

Provenance. Lecture: token allocation, The Pile, mixture-of-experts and data feedback. Gao et al., pp. 1, 3–4; Shazeer et al., pp. 3–5; Fedus et al., pp. 6–7. Original construction: mixture decomposition.

Let bound domain-list index \(j\) identify coding, dialogue, biomedical text or another declared partition, with sampling fraction \(\omega_j\ge0,\sum_j\omega_j=1\). At fixed parameters, aggregate expected loss is exactly \(\sum_j\omega_j\mathcal R_j\), where \(\mathcal R_j\) is expected loss within that domain. This is the law of total expectation, not a fitted scaling law.

To compare old and new aggregate losses, add and subtract the old domain loss under the new mixture:

\[\mathcal R_{\mathrm{new}}-\mathcal R_{\mathrm{old}} =\sum_j\omega_{j,\mathrm{new}}(\mathcal R_{j,\mathrm{new}}-\mathcal R_{j,\mathrm{old}}) +\sum_j(\omega_{j,\mathrm{new}}-\omega_{j,\mathrm{old}})\mathcal R_{j,\mathrm{old}}.\]

The first term describes changed within-domain performance under the new weights; the second describes changed composition evaluated on old performance. Suppose coding loss is 1 nat and other-domain loss is 2 nats at both checkpoints. Changing coding share from 0.50 to 0.25 raises average loss from 1.50 to 1.75 nats without any within-domain degradation. A report that says only “loss rose 0.25” hides this distinction. Use fixed-mixture comparison alongside the production mixture.

The recording describes an illustrative non-English token-share drift from 12% to 19% after a new crawl, approximately 5796–5831 s (speaker judgment, constructed scenario). That is 7 percentage points and a relative increase of \(7/12\approx58.3\%\) (engineering check). It is a detection example rather than a prescribed coding-data allocation. Keep the tokenizer and definition of processed versus unique tokens fixed before comparing shares. A corpus measured in bytes is not automatically a corpus measured in training tokens.

The Pile paper describes 22 component datasets and about 825.18 GiB of text. Its composition table includes sampling weights that determine exposure, not just raw component sizes. A byte share after weighting is not a token share after a chosen tokenizer, and repeated sampling changes training exposure without increasing unique source material. For the zoo and language model alike, preserve a lineage ledger connecting acquisition, filtering, deduplication, partitioning, tokenization and sampler settings.

A mixture-of-experts layer routes each token to a subset of expert networks. Shazeer et al. use sparsely gated experts; Switch Transformers simplify routing to one selected expert per token. Sparse activation can increase stored parameter capacity without applying all experts to every token. It introduces its own diagnostics: selected-expert counts, router confidence, expert capacity, dropped or rerouted tokens, per-expert loss or gradients, and communication cost. A router concentrating work on one expert can cause congestion even when total device utilization looks acceptable.

For a batch with experts indexed by the bound list index \(j\), let \(p_{\mathrm{dispatch},j}\) be the fraction of tokens assigned to expert \(j\) and \(p_{\mathrm{router},j}\) the mean router probability for that expert. Switch's auxiliary term has the form

\[J_{\mathrm{router}}=\lambda_{\mathrm{router}}n_{\mathrm{expert}} \sum_{j=1}^{n_{\mathrm{expert}}}p_{\mathrm{dispatch},j}p_{\mathrm{router},j}.\]

The assignment fractions involve a discrete selection; the probabilities provide a differentiable training signal. If both distributions are uniform, the term is \(\lambda_{\mathrm{router}}\); if both put all mass on one expert, it is \(\lambda_{\mathrm{router}}n_{\mathrm{expert}}\). This comparison explains the intended pressure against collapsed routing. It is not a proof that a product of two arbitrary distributions has its global minimum at uniformity. Router probabilities and selected assignments are coupled by the implementation, which must be specified when analyzing behavior.

If evaluations reveal a coding weakness, changing data shares is a hypothesis to test, not a guaranteed repair. Retrain or continue controlled runs with stated budgets, compare fixed-domain tasks, check retention elsewhere and inspect routing. Monitoring the exposure ledger and the dispatch ledger together can distinguish “the expert never saw the needed data” from “the router rarely sent relevant tokens to it.”

import math


def dot(x, y):
    return sum(a * b for a, b in zip(x, y))


def matvec(matrix, x):
    return [dot(row, x) for row in matrix]


def transpose(matrix):
    return [list(column) for column in zip(*matrix)]


def close(actual, expected, tol=1e-10):
    assert math.isclose(actual, expected, rel_tol=tol, abs_tol=tol), (
        actual, expected)


def dog_probability(x):
    # Stable two-class softmax for logits x[0] and 2*x[1].
    margin = x[0] - 2 * x[1]
    return 1 / (1 + math.exp(-margin))


def relu_score(x):
    return max(0, 2*x[0]-x[1]-1) + 0.5*max(0, x[1])


def relu_gradient(x):
    active = float(2*x[0]-x[1]-1 > 0)
    return [2*active, -active + 0.5*float(x[1] > 0)]


def integrated_gradients(score_gradient, x, baseline, intervals):
    # Right-endpoint rectangle rule, not exact integration.
    displacement = [a-b for a, b in zip(x, baseline)]
    sums = [0.0]*len(x)
    for step in range(1, intervals+1):
        fraction = step/intervals
        point = [b+fraction*d for b, d in zip(baseline, displacement)]
        for i, value in enumerate(score_gradient(point)):
            sums[i] += value
    return [d*s/intervals for d, s in zip(displacement, sums)]

def full_convolution(x, kernel):
    result = [0.0]*(len(x)+len(kernel)-1)
    for i, value in enumerate(x):
        for j, weight in enumerate(kernel):
            result[i+j] += value*weight
    return result


def pooled_and_unpooled(window):
    maximum = max(window)
    switch = window.index(maximum)  # deterministic first-maximum convention
    unpooled = [0.0]*len(window)
    unpooled[switch] = maximum
    return maximum, unpooled

19. Six exercises with complete solutions

Each exercise asks for a quantity, assumptions and an interpretation. Arithmetic alone is insufficient when two methods compute different objects.

Exercise 1 · A falling competitor and a saturated detector

For \(u_{\mathrm{dog}}=x_1,u_{\mathrm{cat}}=2x_2\), hold \(x_1=1\) and change \(x_2\) from 1 to 0. Calculate both probabilities and both derivatives of the dog probability at the initial point. Then consider \(u(x)=\min(1,\max(0,x))\) at \(x=2\). Calculate local saliency and integrated gradients from baselines 0 and 1.5. Explain what each method can conclude about “dog evidence.”

Solution

The dog probability is \(1/(1+\exp(2x_2-x_1))\), hence initially \(1/(1+e)=0.268941\) and finally \(1/(1+e^{-1})=0.731059\). If this probability is \(p_{\mathrm{dog}}\), its derivative with respect to \(x_1\) is \(p_{\mathrm{dog}}(1-p_{\mathrm{dog}})=0.196612\); with respect to \(x_2\) it is \(-2p_{\mathrm{dog}}(1-p_{\mathrm{dog}})=-0.393224\). The dog logit remains 1, with derivatives \((1,0)\). Thus the probability change reflects the competitor's score, and a probability gradient mixes competitors' contributions.

For the saturated detector, the derivative at 2 is 0. Along the baseline-0 path \(2\zeta\), the derivative is 1 for \(0<\zeta<1/2\) and 0 afterward. Integrated gradients is \(2\int_0^{1/2}1\,d\zeta=1=u(2)-u(0)\). From baseline 1.5, every point on the path is saturated; the integral is 0 and the endpoint difference is also 0. These are consistent statements about different references. Zero local derivative means local insensitivity, not absence of all past or reference-relative contribution. A baseline must be justified for the intended comparison.

Exercise 2 · Integrated gradients through a kink

For \(u(x)=\max(0,2x_1-x_2-1)+\frac12\max(0,x_2)\), explain \(x=(2,1)\) relative to zero. Derive both integrated gradients exactly, compare their sum with the endpoint gradient dotted into the displacement, and calculate the two-interval right-endpoint approximation. Does a small completeness residual guarantee that each coordinate is accurate?

Solution

The path is \((2\zeta,\zeta)\). The first preactivation is \(3\zeta-1\), active for \(\zeta>1/3\); the second is active for \(\zeta>0\). Away from the kinks, the gradient is \((0,1/2)\) before \(1/3\) and \((2,-1/2)\) after it. Therefore \(\mathrm{IG}_1=2\int_{1/3}^1 2\,d\zeta=8/3\), while \(\mathrm{IG}_2=\int_0^{1/3}1/2\,d\zeta+\int_{1/3}^1(-1/2)\,d\zeta=-1/6\). Their sum is \(5/2\), matching \(u(2,1)-u(0,0)\).

The endpoint gradient is \((2,-1/2)\); its dot product with \((2,1)\) is \(7/2\). Extending a local derivative across the full displacement ignores the kink. With two right-endpoint samples at \(1/2,1\), both gradients equal \((2,-1/2)\), so the approximation is \((4,-1/2)\), sum \(7/2\), with residual 1. The coordinate error can be much larger than the sum residual: adding \(c\) to one estimate and subtracting \(c\) from the other leaves the residual unchanged. Check convergence of individual coordinates as well as the sum, and handle known discontinuities explicitly if exact integration is available.

Exercise 3 · CAM identity, scale and a nonlinear counterexample

Use feature maps \((1,2,3,4)\) and \((4,3,2,1)\), head weights \((2,-1)\) and bias 0.5. Compute pooled activations, logit, CAM and raw Grad-CAM before its outer ReLU. Why does averaging CAM recover the logit only after adding the bias? Show that moving a ReLU across spatial averaging changes the function using map \((0,2)\) and threshold 1.

Solution

Both pooled activations are 2.5. The logit is \(2(2.5)-2.5+0.5=3\). CAM is the pointwise weighted sum \((-2,1,4,7)\), with mean 2.5. Its definition omits the spatially constant bias; adding 0.5 recovers the logit. Because a mean pool has derivative \(1/4\), the class-score gradient with respect to every entry of a given channel is \(W_{k\nu}/4\). Grad-CAM's mean gradient weights are therefore \((1/2,-1/4)\); its raw map is CAM divided by 4, namely \((-0.5,0.25,1,1.75)\). The outer ReLU removes the negative coordinate, so its mean no longer gives the exact original logit decomposition.

For \((0,2)\), ReLU after averaging and subtracting 1 gives \(\max(0,(0+2)/2-1)=0\). Averaging pointwise \(\max(0,h-1)\) gives \((0+1)/2=0.5\). Thus the exact linear-head CAM identity cannot be carried through an arbitrary nonlinear head. Retraining a new GAP-and-linear head produces a new function whose identity holds; it does not prove that it explains the former head.

Exercise 4 · The adjoint, the padding boundary and lost information

Use the eight-entry convolution in sections 9–10. Derive \(W_{\mathrm{in}}^\top\), \(W_{\mathrm{in}}W_{\mathrm{in}}^\top\) and the minimum-norm preimage of \(u=(2,3,3,3,-7)\). Give a nonzero null-space vector. Explain why \(\frac12W_{\mathrm{in}}^\top\) fails as a right inverse although \(\frac12W^\top\) works on the unrestricted padded domain. State what transposed convolution contributes to a decoder.

Solution

Each output's coefficient is placed back on the input coordinates it touches, giving \(W_{\mathrm{in}}^\top \upsilon=(-\upsilon_2,\upsilon_1,-\upsilon_3,\upsilon_2,-\upsilon_4,\upsilon_3,-\upsilon_5,\upsilon_4)\). Rows touch disjoint coordinates; their squared norms are \(1,2,2,2,1\). Thus \(W_{\mathrm{in}}W_{\mathrm{in}}^\top=\operatorname{diag}(1,2,2,2,1)\), and \(W_{\mathrm{in}}^+=W_{\mathrm{in}}^\top(W_{\mathrm{in}}W_{\mathrm{in}}^\top)^{-1}\). Its application gives \((-1.5,2,-1.5,1.5,-1.5,1.5,7,1.5)\). This vector reproduces \(u\) and lies in the row space, orthogonal to the null space, which proves minimum norm: any other preimage is this vector plus a null-space vector, adding its squared norm by orthogonality.

One null vector is \((1,0,0,1,0,0,0,0)\). The padded-domain \(W\) uses two nonzero entries in every row, including padding coordinates, so \(WW^\top=2I\). Fixing padding to zero removes one entry from each boundary row. Applying \(\frac12W_{\mathrm{in}}^\top\) therefore yields half the required first and last output on reapplication. Transposed convolution supplies a shape-expanding adjoint operation, or a learned map with that structure; it cannot identify the null-space component that the encoder discarded. Decoder quality must be evaluated as prediction or reconstruction under a stated data distribution.

Exercise 5 · A gallery, a switch and an attention display

A channel's top nine examples all contain dogs and fences. A guided-backprop image highlights fur. A transformer head places 90% attention on one of two positions whose scalar values both equal 2. Give one falsifiable test for each interpretation. Also determine whether switch unpooling recovers a window \((-4,-3,-2,-1)\), and list the three ReLU backward signals at \(u=-2,\upsilon=3\).

Solution

Expand the gallery with dogs without fences and fences without dogs, holding channel and preprocessing fixed. If fence-only cases activate strongly while fence-free dogs do not, the exclusive dog-detector hypothesis fails. Selection remains a limitation even if the first added cases agree, so preserve the sampling rule and full images. For guided backpropagation, compare randomized-parameter and trained-model outputs with fixed display scales, then perform foreground or background interventions and measure the ordinary dog logit. An unchanged guided picture under randomization weakens its use as evidence of learned dog dependence.

The attention output is \(0.9(2)+0.1(2)=2\); swapping the weights gives 2 again. Intervene on a value or on a specific head contribution and measure the downstream scalar, recognizing that token replacement modifies multiple paths. The equal-value example already refutes the inference that the larger weight uniquely explains this head's output value. Zero-filled switch unpooling places \(-1\) at the fourth position, giving \((0,0,0,-1)\); re-pooling gives 0. It is not recovery, nor a right inverse here. At \(u=-2,\upsilon=3\), ordinary backpropagation gives 0, deconv gives 3 and guided gives 0. A visually appealing method cannot silently substitute for ordinary differentiation.

Exercise 6 · Diagnose an aggregate regression

A coding domain has loss 1 nat and another domain loss 2 nats under both checkpoints. Coding weight changes from 0.50 to 0.25. Separately, a paired evaluation of ten independent cases gives four new-model wins, one loss and five ties. Compute the aggregate loss change, paired accuracy change and its estimated standard error. Under \(C_{\mathrm{train}}=6N_{\mathrm{param}}N_{\mathrm{tok}}=600\) and illustrative excess risk \(1/N_{\mathrm{param}}+1/N_{\mathrm{tok}}\), find the optimum. Finish with an investigation plan that separates these quantities from jailbreak and agent-latency changes.

Solution

The old aggregate loss is \(0.5(1)+0.5(2)=1.5\); the new is \(0.25(1)+0.75(2)=1.75\). The increase 0.25 comes entirely from composition. On paired cases, \(\widehat{\mathrm{Gain}}=(4-1)/10=0.3\). Since \(\sum_i\mathrm{Diff}_i^2=5\), \(\sum_i(\mathrm{Diff}_i-\widehat{\mathrm{Gain}})^2=5-10(0.3)^2=4.1\). Thus \(\widehat{\mathrm{Var}}_{\mathrm{Diff}}=4.1/9\) and the estimated standard error is \(\sqrt{4.1/90}=0.213437\). This small sample supports considerable uncertainty; it does not establish a precise population improvement. Correlated cases would require a different uncertainty calculation.

The compute constraint gives \(N_{\mathrm{tok}}=100/N_{\mathrm{param}}\). Excess risk is \(1/N_{\mathrm{param}}+N_{\mathrm{param}}/100\), whose derivative is \(-1/N_{\mathrm{param}}^2+1/100\). Its positive stationary point is \(N_{\mathrm{param}}=10\), \(N_{\mathrm{tok}}=10\), with excess risk 0.2; the second derivative \(2/N_{\mathrm{param}}^3>0\) and divergent boundary behavior establish the minimum. Counts here are toy continuous quantities; actual feasible architectures are discrete.

First compare domain losses under a fixed evaluation mixture and inspect paired task disagreements. Then freeze adversarial prompts, tool permissions and safeguard settings for a separate jailbreak comparison. For latency, separate model time, queueing and tool time, and replay identical tool responses. Align the optimizer and data timelines to locate candidate causes, then run bounded matched interventions. None of the arithmetic above establishes why jailbreaks or latency changed, and an allocation optimum does not repair an identified corruption event.
